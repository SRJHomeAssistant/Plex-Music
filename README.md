# Plex Music v1.0.0 — Stream Plex Music to Alexa Echo's 🎵

## Features

- Play and shuffle songs, artists and albums from Plex using Alexa.
- Smarter album matching, including Frozen 2 → Frozen II.
- MP3 playback and Plex transcoding for compatible formats.
- Alexa playback controls, queues and resume support.
- Home Assistant playback status, diagnostics and album artwork.
- Self-hosted with no AWS hosting or unofficial Alexa API.

## Installation

Add this repository to Home Assistant Marketplace:

[https://github.com/SRJHomeAssistant/Plex-Music](https://github.com/SRJHomeAssistant/Plex-Music)

Install v1.0.0, restart Home Assistant and configure Plex Music.
